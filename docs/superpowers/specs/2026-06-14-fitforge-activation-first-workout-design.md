# FitForge 激活与首次训练设计

> 已于 2026-07-19 被 `2026-07-19-fitforge-product-scope-membership-level-redesign.md` 替代。训练画像、画像推荐和相关事件方案均不再属于当前产品范围；本文仅作为历史决策记录。

## 1. 目标

帮助首次进入或尚未启用计划的用户，用最少决策获得一套可执行计划，并在 24 小时内完成第一次有效训练。

## 2. 范围

### 包含

- 首次画像采集。
- 推荐计划生成与预览。
- 推荐计划启用。
- 首页未启用计划状态改造。
- 基础训练记录免费边界调整。
- 产品事件埋点。
- 数据导出、训练数据删除与账号注销入口。

### 不包含

- 自动生成全新训练模板。
- AI 对话式问诊。
- 医疗建议。
- 修改现有计划执行状态计算。

## 3. 推荐方案选择

采用“系统计划匹配”而不是立即生成用户自定义计划：

- 复用现有系统计划、系统模板和计划启用能力。
- 根据画像条件为系统计划计算匹配分并排序。
- 推荐结果展示匹配原因和不匹配项。
- 用户可以直接启用，也可以进入计划列表自行选择。

该方案开发边界清晰，能够快速验证推荐是否提升首训完成率。个性化生成计划不进入本阶段。

## 4. 首次画像

### 4.1 入口规则

满足以下任一条件时，首页展示“生成适合我的计划”：

- 用户已登录但未完成首次画像。
- 用户已完成画像但没有推荐结果和启用计划。

未登录用户点击后先完成登录，再返回画像流程。登录成功后不得跳回首页丢失上下文。

### 4.2 四步流程

#### 第一步：训练目标

单选：

- 增肌 `MUSCLE_GAIN`
- 提升力量 `STRENGTH`
- 减脂塑形 `FAT_LOSS`
- 保持健康 `GENERAL_FITNESS`

页面说明：选择主要目标，后续仍可在个人资料中修改。

#### 第二步：训练安排

- 每周训练次数：2、3、4、5 次。
- 单次时长：30、45、60、75 分钟。
- 偏好训练日：周一至周日，多选，可跳过。

约束：

- 每周训练次数必选。
- 偏好日少于训练次数时允许继续，推荐结果解释“其余训练日可灵活安排”。

#### 第三步：训练条件

训练环境单选：

- 健身房器械较全 `FULL_GYM`
- 家庭哑铃或弹力带 `HOME_BASIC`
- 徒手训练 `BODYWEIGHT_ONLY`

可用器械多选，用于解释推荐结果；本阶段不逐动作替换计划。

#### 第四步：经验与限制

- 训练经验：新手、有一些经验、稳定训练一年以上。
- 不适或限制部位：肩、腰、膝、腕、其他、无。

限制信息只用于提示用户检查计划，不生成医疗结论。存在限制时，推荐结果展示：

> 你标记了膝部不适，开始前请检查计划动作，并根据实际情况调整或咨询专业人士。

### 4.3 保存与恢复

- 每完成一步立即保存草稿。
- 用户退出后，首页主行动变为“继续完善训练方案”。
- 返回流程时定位到第一个未完成步骤。
- 修改已完成步骤后，旧推荐结果标记为失效，需要重新计算。

## 5. 推荐计划

### 5.1 匹配维度

系统计划按以下顺序计算匹配：

1. 训练目标。
2. 每周训练次数。
3. 训练经验与计划难度。
4. 单次训练时长与模板预计时长。
5. 器械适配程度。

推荐结果最多展示三个计划：

- 第一名：标记“最适合你”。
- 第二、三名：作为可选方案。

### 5.2 推荐结果页面

首屏内容：

- 推荐计划名称。
- 周期、每周次数、预计时长。
- 三条匹配原因。
- 第一周训练安排。
- 主按钮“启用并开始第一周”。
- 次按钮“查看其他计划”。

匹配原因示例：

- 每周安排 3 次，符合你的时间。
- 训练时长约 45 分钟。
- 适合力量训练新手。

### 5.3 启用规则

- 继续复用现有“本周生效”和“下周生效”能力。
- 推荐流程默认选择后端返回的推荐启用模式。
- 用户可以展开查看另一种启用方式。
- 启用成功后回到首页；若今日存在可训练计划日，主行动为“开始第一次训练”。

## 6. 首页状态设计

优先级从高到低：

1. 有可恢复训练草稿：继续训练。
2. 今日有待完成计划日：开始今日计划。
3. 有逾期训练日：安排错过的训练。
4. 未完成画像：生成或继续完善训练方案。
5. 已有推荐未启用：查看推荐计划。
6. 无计划但已完成画像：选择训练计划。
7. 今日已完成：查看训练总结或下次安排。

页面不得同时突出两个同权重 CTA。

## 7. 免费边界调整

### 7.1 免费用户允许

- 不限次数开始、完成和保存训练。
- 查看最近训练记录。
- 查看基础周统计。
- 使用系统计划和系统模板。
- 使用训练草稿。

### 7.2 保持为 Pro

- 无限自定义计划与模板。
- 高级训练建议。
- 高级分析。
- 自动化数据导出和完整历史趋势。
- 后续高级排程能力。

现有训练保存前的会员阻断应移除。会员页仍可从高级能力入口触达。

## 8. 数据与隐私入口

在“我的 → 设置”新增“数据与隐私”分组：

- 导出训练数据。
- 导出身体指标。
- 删除训练数据。
- 注销账号。

### 8.1 导出

- 用户选择导出内容。
- 系统生成 CSV 或 JSON 文件。
- 生成中显示任务状态。
- 完成后提供下载或系统分享。
- 文件包含生成时间和数据范围。

### 8.2 删除训练数据

- 独立确认页说明将删除训练记录、统计和 PR。
- 输入确认文案或二次确认后执行。
- 不删除账号和个人资料。
- 执行成功后刷新首页、历史和分析缓存。

### 8.3 注销账号

- 明确说明注销会删除或匿名化的数据范围。
- 要求重新确认身份。
- 注销完成后清除本地 Token、画像草稿、训练草稿和缓存。

## 9. 建议数据契约

### 9.1 用户画像

```ts
interface TrainingProfile {
  status: 'NOT_STARTED' | 'IN_PROGRESS' | 'COMPLETED'
  goal?: 'MUSCLE_GAIN' | 'STRENGTH' | 'FAT_LOSS' | 'GENERAL_FITNESS'
  sessionsPerWeek?: number
  sessionDurationMinutes?: number
  preferredDays?: number[]
  environment?: 'FULL_GYM' | 'HOME_BASIC' | 'BODYWEIGHT_ONLY'
  equipment?: string[]
  experienceLevel?: string
  limitations?: string[]
  updatedAt?: string
}
```

### 9.2 推荐结果

```ts
interface RecommendedPlan {
  recommendationId: string
  planId: number
  score: number
  reasons: string[]
  cautions: string[]
  recommendedActivationMode: 'THIS_WEEK' | 'NEXT_WEEK'
}
```

推荐结果必须引用现有计划 ID，不复制计划内容。

## 10. 埋点

| `onboarding_started` | `source_page` |
| `onboarding_step_completed` | `step`, `elapsed_seconds` |

## 11. 异常与边界

- 推荐接口失败：保留画像，提供重试和“浏览全部计划”。
- 没有合适系统计划：展示最接近方案并解释差异，不伪造完美匹配。
- 用户未登录：保存本地画像草稿，登录成功后提交。
- 启用计划失败：保留当前推荐页和选择，不返回首页。
- 删除或注销请求失败：不清除本地数据，明确提示重试。

## 12. 验收标准

- 新用户最多完成四步即可看到推荐计划。
- 流程退出后可从原步骤继续。
- 推荐页能说明为什么推荐。
- 用户能够在推荐页直接启用计划。
- 免费用户可以连续保存多次训练，不出现会员阻断。
- 首页所有状态只有一个主行动。
- 数据导出、训练数据删除和账号注销均有明确进度与结果反馈。
- 能通过埋点计算首次画像完成率和 24 小时首训完成率。
