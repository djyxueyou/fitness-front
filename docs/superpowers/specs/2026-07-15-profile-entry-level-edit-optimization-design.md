# FitForge 我的页、等级详情与编辑资料优化设计

## 目标

消除“我的”页顶部个人资料与等级详情共用一个视觉入口造成的歧义，修正等级路线把段位顺序误写成等级数字的问题，并精简编辑资料页的重复导航。

## 我的页

- 顶部概览继续使用一个分组容器，内部拆为身份区、等级区和统计区。
- 身份区展示头像、昵称和明确的“编辑资料”动作，点击整行进入编辑资料页。
- 等级区独立成行，展示当前等级、段位、升级所需 XP、进度条和“等级详情”动作，点击整行打开等级弹层。
- 身份区与等级区不得使用嵌套点击热区。
- 菜单行恢复辅助说明；“设置”继续作为入口名称，辅助说明为“训练、单位与应用偏好”。
- 退出登录降低视觉权重，但保留既有确认流程。

## 等级详情弹层

- 弹层遮罩覆盖完整视口，弹层高度提高，顶部标题和底部操作固定，中间内容独立滚动。
- 顶部主卡继续展示用户当前真实等级，例如“Lv.7 · 白银”。
- 等级路线中的卡片代表段位而不是单个等级：徽章只显示段位名，卡片下方展示真实范围。
- 段位范围固定为：青铜 Lv.1–5、白银 Lv.6–10、黄金 Lv.11–20、铂金 Lv.21–35、钻石 Lv.36–55、星耀 Lv.56–80、荣耀 Lv.81+。
- 当前段位显示“当前”标签和强调边框，尚未解锁的段位显示“未解锁”文字并降低视觉强度。
- 等级路线不得再按数组索引显示 Lv.1、Lv.2、Lv.3。
- 主按钮文案调整为“去完成有效训练”，次按钮继续为“查看训练分析”。

## 编辑资料页

- 删除“身体指标”和“训练偏好”两个跳转入口及其未保存跳转确认逻辑。
- 页面只保留头像、昵称、身高、训练目标、训练经验和保存操作。
- 训练目标、训练经验以中文标签显示，但保存时继续使用后端既有代码值。
- 兼容旧版本可能保存的中文值，加载时将中文值归一化为对应代码。
- 训练目标与训练经验的选中状态同时使用背景、边框和对勾文字，不只依赖颜色。
- 头像操作文案改为“更换头像”，不再使用文本符号模拟相机图标。
- 保存按钮状态区分“已保存”“保存资料”“保存中...”。

## 设置命名

- 我的页入口保留“设置”，不改成“训练偏好”。
- “训练偏好”继续用于训练目标、经验、频率、环境等训练画像概念。
- 本轮不重构设置页内容，只更新我的页辅助说明，避免扩大三页优化范围。

## 技术范围

- 仅修改 `fitness-front/`。
- 不修改后端接口、数据库和 API 数据结构。
- 复用现有主题变量、卡片、按钮和训练等级徽章组件。
- 支持 H5 与微信小程序构建，保留亮色和暗色主题。

## 验收标准

- 我的页首次查看时，“编辑资料”和“等级详情”是两个独立且明确的整行操作。
- 点击等级区不会触发资料编辑导航。
- 等级路线不出现按段位顺序生成的 Lv.1、Lv.2、Lv.3；所有范围与实际配置一致。
- 编辑资料页不请求身体指标，不出现“身体指标”或“训练偏好”跳转入口。
- `FAT_LOSS`、`BEGINNER` 等内部代码不直接显示给用户。
- 所有目标和经验选项都能正确回显、选择并以代码值保存。
- 前端单测、格式检查、类型检查和微信小程序构建通过。
