# FitForge 高效训练与智能进阶设计

## 1. 目标

减少训练中的输入和决策成本，并基于用户历史表现提供可解释、可忽略、可调整的下一组和下一次训练建议。

## 2. 范围

### 包含

- RPE/RIR 记录。
- 规则驱动的渐进超负荷建议。
- 一键沿用上次表现。
- 快速增减重量、次数和时长。
- 热身组生成。
- 杠铃配片计算。
- 超级组。
- 动作快速替换。
- 休息计时反馈。

### 不包含

- 自动调整整套训练计划。
- 医疗或伤病诊断。
- 基于大模型的训练处方。
- 修改修为结算。

## 3. 训练中页面结构

页面优先级：

1. 顶部：训练名称、来源、计时、总进度、完成训练。
2. 当前动作摘要：动作名称、当前组、上次表现、本次建议。
3. 当前动作组记录：当前组突出，其他组降低视觉权重。
4. 当前动作操作：完成动作、添加组、动作菜单。
5. 后续动作列表：折叠摘要。

训练中不得要求用户进入二级页面才能完成重量、次数、时长和完成组记录。

## 4. RPE/RIR 设计

### 4.1 记录方式

完成训练组后，显示可选的“本组余力”轻提示：

| 选项 | 存储值 | 用户文案 |
| --- | --- | --- |
| 轻松 | `RIR_4_PLUS` | 还能完成 4 次以上 |
| 合适 | `RIR_2_3` | 还能完成 2–3 次 |
| 较难 | `RIR_1` | 还能完成 1 次 |
| 力竭 | `RIR_0` | 已无法继续 |
| 失败 | `FAILED` | 未完成目标 |

默认不强制选择。用户可以在设置中开启“每组完成后询问余力”。

### 4.2 展示规则

- 当前组完成后以底部轻量面板出现。
- 选择后自动关闭，并启动休息计时。
- 用户未选择时不阻塞下一组。
- 已完成组可在动作菜单中修改余力。

## 5. 渐进建议

### 5.1 建议单位

建议作用于“下一次该动作的工作组目标”，而不是静默改写当前训练。

建议包含：

- 建议重量、次数或时长。
- 建议组数。
- 建议原因。
- 规则版本。
- 置信状态：数据不足、普通、较高。

### 5.2 首版规则

#### 负重次数动作

- 全部目标组完成，最近有效余力为 2 次以上：重量增加一个最小增量。
- 全部目标组完成，但最近有效余力为 0–1 次：保持重量。
- 未完成一组：保持重量并降低目标次数上限。
- 连续两次未完成目标：降低 5% 重量。
- 无历史记录：使用模板目标，不生成进阶结论。

#### 自重次数动作

- 全部目标组完成且余力充足：每组增加 1–2 次。
- 连续达到次数上限：建议切换进阶动作，仅提示，不自动替换。
- 连续两次未完成：保持次数或减少一组。

#### 计时动作

- 全部完成且余力充足：每组增加 5–10 秒。
- 未完成：保持或减少 5 秒。

### 5.3 推荐交互

当前动作摘要展示：

> 本次建议：22.5kg × 10 次  
> 原因：上次完成全部目标组，且仍有约 2 次余力。

操作：

- “应用到未完成组”
- “保持当前目标”
- “调整建议”

用户应用后又修改，记录为 `OVERRIDDEN`，用于后续评估规则质量。

## 6. 高效记录能力

### 6.1 一键沿用上次表现

- 动作首次展开时，如果存在历史表现，展示“沿用上次”。
- 点击后只填充未完成组。
- 不覆盖模板明确设置的目标，除非用户二次确认。

### 6.2 快速增减

- 重量默认步长：2.5kg，可在设置调整。
- 次数默认步长：1 次。
- 时长默认步长：5 秒。
- 长按连续调整，松开停止。

### 6.3 热身组

动作菜单提供“生成热身组”：

- 根据首个工作组重量生成最多三组热身组。
- 热身组标记为 `WARMUP`。
- 热身组不计入工作组完成率和进阶判断。
- 用户可删除或修改。

### 6.4 杠铃配片计算

输入：

- 目标总重量。
- 杠铃杆重量。
- 可用杠铃片规格。

输出：

- 单侧需要的杠铃片组合。
- 无法精确组成时展示最接近的低值和高值。

该工具为本地计算，不依赖后端。

### 6.5 超级组

- 用户可在动作菜单中选择“与其他动作组成超级组”。
- 超级组使用相同颜色标识和组名。
- 完成一组后，下一主行动跳到超级组中的下一个动作。
- 超级组结束后再启动完整休息计时。

### 6.6 动作快速替换

- 从动作菜单进入动作选择器。
- 默认筛选相同主要肌群和相近器械。
- 替换前显示目标组是否可继承。
- 已完成组不允许被替换；需要替换时先确认移除已完成记录。

## 7. 休息计时

- 完成工作组后自动启动默认休息时长。
- 完成热身组使用较短默认时长。
- 倒计时可暂停、增加 30 秒、立即结束。
- 离开训练页后继续计时。
- 到时使用震动、声音或系统通知能力中的可用项；用户可在设置中关闭。

## 8. 建议数据契约

### 8.1 训练组扩展

```ts
interface WorkoutSetInput {
  weightKg?: number
  reps?: number
  durationSeconds?: number
  setType: 'NORMAL' | 'WARMUP' | 'DROP' | 'FAILURE'
  effort?: 'RIR_4_PLUS' | 'RIR_2_3' | 'RIR_1' | 'RIR_0' | 'FAILED'
}
```

### 8.2 动作建议

```ts
interface ExerciseProgressionRecommendation {
  recommendationId: string
  exerciseId: number
  recordType: string
  targetSets: number
  targetWeightKg?: number
  targetReps?: number
  targetDurationSeconds?: number
  reasonCode: string
  reasonText: string
  confidence: 'LOW' | 'MEDIUM' | 'HIGH'
  ruleVersion: string
}
```

### 8.3 推荐反馈

```ts
interface RecommendationFeedback {
  recommendationId: string
  action: 'APPLIED' | 'DISMISSED' | 'OVERRIDDEN'
  appliedAt: string
}
```

## 10. 异常与边界

- 历史数据不足：展示模板目标，不展示推荐原因。
- 用户没有记录 RIR：仅基于完成情况给出保守建议。
- 推荐接口失败：训练照常进行，保留模板目标和上次表现。
- 修改已完成组：需要明确确认，并重新计算建议反馈状态。
- 热身组和工作组必须明确区分，避免统计污染。
- 超级组任一动作被删除时，解除该动作关系，其他动作继续保留。

## 11. 验收标准

- 用户无需离开训练页即可完成所有基础记录。
- RPE/RIR 为可选项，不阻塞完成训练。
- 推荐始终包含原因，不自动覆盖用户输入。
- 用户可以一键应用上次表现或建议到未完成组。
- 热身组不计入工作组完成率和进阶规则。
- 超级组能正确引导下一个动作和休息计时。
- 推荐接口失败不影响训练完成和保存。
