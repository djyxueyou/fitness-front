# FitForge 产品范围、会员与等级重构设计

日期：2026-07-19

状态：已实施；周统计、自定义计划和系统计划边界以 2026-07-20 规格的 2026-07-22 修订为准

## 1. 文档地位

本文是本轮产品重构的统一规格。此前文档与本文冲突时，以本文为准。

本文明确替代以下旧结论：

- 新用户需要填写训练画像或通过画像获得推荐计划。
- 首页需要展示“建立训练画像”或“完善训练偏好”。
- 新用户登录后自动获得 30 天 Pro 试用。
- 动作收藏属于免费能力。
- 免费用户可以查看基础周统计。
- 等级经验与 30/60 分钟训练门槛、连续训练天数绑定。
- 当前阶段建设产品事件漏斗、计划/周报公开分享、归因二维码。

历史设计文档保留为决策过程记录，但实施时必须在冲突文档顶部增加“已被本文替代”的状态说明，不直接删除历史文档。

## 2. 背景与目标

FitForge 尚未正式上线，不需要兼容线上用户的画像、自动试用和旧等级数据。本轮可以直接清理无效结构，避免长期同时维护新旧模型。

本轮目标：

1. 删除没有形成真实推荐价值的用户画像，让新用户直接选择并启用训练计划。
2. 落地会员方案 A：训练记录免费，效率工具、内容创建扩展、周期统计和专业分析付费。
3. 取消自动试用，使免费版承担核心价值体验，付费只在用户主动使用 Pro 能力时发生。
4. 简化等级经验规则，奖励有效训练、计划执行和真实进步，不奖励拖时长或连续打卡。
5. 缩小当前版本范围，不建设事件漏斗、公开分享、二维码和归因能力。
6. 同步更新产品文档、接口说明、数据库注释和必要的业务注释，保证后续事实来源统一。

## 3. 产品原则

1. 核心训练免费：用户可以不限次数开始、保存、查看单次训练。
2. 自主选择计划：计划中心提供筛选和清晰说明，不伪装成个性化推荐。
3. 付费边界明确：点击 Pro 能力时直接解释权益，不先展示假数据或模糊结果。
4. 用户资产不丢失：会员到期或额度降低不删除用户已创建的数据。
5. 执行信息与统计分离：完成计划所需的日程、状态和首页基础“本周节奏”免费；周统计详情、历史周趋势、周报和高级分析属于 Pro。
6. 数据库按未上线产品处理：删除废弃字段和代码，不为不存在的线上历史版本保留兼容分支。
7. 历史记录不可变：删除画像或调整会员规则不得改变既有训练记录的含义。

## 4. 新用户与计划路径

### 4.1 目标路径

```text
进入首页
  -> 登录
  -> 浏览计划中心
  -> 按目标、难度、频率、器械条件筛选
  -> 查看系统计划详情
  -> 调整训练日和动作
  -> 预览并启用
  -> 开始今日训练
```

计划中心统一使用“训练计划”或“系统计划”等真实命名，不使用“为你推荐”“根据画像匹配”等文案。

### 4.2 彻底删除训练画像

前端删除：

- `pages/onboarding/index` 页面与路由。
- onboarding Store、API 类型和本地缓存。
- 首页 `needsOnboarding`、画像加载、画像 CTA 和跳转分支。
- 个人资料或设置中的训练画像、训练偏好入口。
- 用户可见的训练目标、经验等级等仅为画像服务的编辑项。
- 与画像推荐结果、推荐理由和推荐状态相关的遗留文案与类型。

后端删除：

- `/api/user/training-profile` 读写接口。
- 画像请求/响应 DTO、校验逻辑和 Service 方法。
- 训练目标、经验等级、每周次数、单次时长、训练环境、训练限制、画像步骤和完成状态等画像字段。
- 画像匹配计划的 Controller、Service、DTO 与测试残留。

数据库处理：

- 在增量 SQL 中删除画像相关列或废弃表。
- 同步更新 `schema.sql`，确保新建数据库不再产生画像结构。
- 开发环境已有画像数据无需迁移到其他字段，可以直接删除。

用户昵称、头像、单位偏好、默认休息时间、进阶步长和身体指标不属于训练画像，继续保留。

### 4.3 计划中心规则

- 计划列表是自主浏览和筛选，不建立“先推荐、后浏览”两套模式。
- 计划卡片展示目标、难度、每周频率、预计时长、器械条件和适合人群。
- 系统计划浏览、详情、调整和启用均为免费能力。
- 免费用户可以创建、复制和维护 1 个有效“我的计划”，Pro 数量不限。
- 首页无有效计划时，主按钮统一为“选择训练计划”。

## 5. 首页状态

首页保留一个视觉上最明确的主焦点卡片，但不删除其下的自由训练、模板、数据分析等快捷入口。

| 用户状态 | 主卡片 | 主按钮 |
| --- | --- | --- |
| 未登录 | 登录后保存训练数据 | 登录 |
| 已登录、无有效计划 | 选择适合自己的训练计划 | 选择计划 |
| 今日有计划 | 今日训练内容 | 开始训练 |
| 今日休息 | 今日恢复日 | 查看计划 |
| 今日已完成 | 今日训练已完成 | 查看训练总结 |
| 存在未完成草稿 | 继续上次训练 | 继续训练 |

主焦点优先级：未完成草稿 > 登录 > 今日计划状态 > 无计划。

首页不得再出现“建立训练画像”“完善训练偏好”或同义状态。

## 6. 会员方案 A

### 6.1 最终权益矩阵

| 功能 | 免费用户 | Pro 会员 |
| --- | --- | --- |
| 开始、保存训练 | 不限 | 不限 |
| 单次训练详情与完整训练历史 | 不限 | 不限 |
| 系统动作浏览、搜索和使用 | 支持 | 支持 |
| 动作收藏 | 不支持 | 不限 |
| 自定义动作 | 当前最多 1 个 | 不限 |
| 自定义训练模板 | 当前最多 1 个 | 不限 |
| 系统训练模板浏览和使用 | 支持 | 支持 |
| 系统计划浏览、调整和启用 | 支持 | 支持 |
| 有效“我的计划” | 最多 1 个 | 不限 |
| 首页当前周“本周节奏” | 支持 | 支持 |
| 周统计详情、周报及历史周趋势 | 不支持 | 支持 |
| 高级分析、长期趋势和训练洞察 | 不支持 | 支持 |
| 训练进阶目标与解释 | 不支持 | 支持 |

“当前最多 1 个”按未删除的有效记录数量计算，不按历史创建次数计算。用户删除后可以重新创建。

### 6.2 动作收藏

- 收藏列表、添加收藏、取消收藏都要求有效 Pro 会员。
- 免费用户在动作列表或详情点击收藏时，展示会员权益说明，不修改收藏状态。
- 免费用户直接进入收藏页时展示 Pro 权益空态，不请求或展示收藏数据。
- Pro 到期后保留收藏关系，不删除数据库记录；重新开通后恢复。
- 收藏数量不设置上限。

### 6.3 自定义动作和训练模板额度

免费额度：

- 1 个自定义动作。
- 1 个自定义训练模板。

额度由后端强制执行，前端只用于提前展示数量和友好提示。

创建规则：

- 当前数量低于 1 时允许创建。
- 当前数量等于 1 时，创建或复制操作提示升级 Pro。
- 从训练记录“保存为模板”也属于创建模板，使用同一额度。
- 删除已有内容后额度立即释放。
- 并发创建由服务端事务或等效并发保护保证不能突破额度。

会员到期或退款后的超额处理：

- 不删除任何自定义动作、模板及其历史引用。
- 用户可以查看并在历史训练中继续识别这些数据。
- 超额状态下不能新增、复制或编辑自定义内容。
- 删除操作始终允许，用户删减到免费额度后恢复剩余内容的编辑能力。
- 重新开通 Pro 后立即恢复新增和编辑能力。

系统动作、系统模板不计入免费额度。

### 6.4 首页基础本周节奏免费，统计详情属于 Pro

登录用户可在首页免费查看当前自然周的训练次数、累计时长、累计容量和 7 日训练分布。以下更完整的统计与分析能力要求有效 Pro：

- 计划周完成率统计。
- 与上一周的比较。
- 肌群训练分布。
- 动作表现周趋势。
- 周报结论、关注项和下周建议。

免费用户仍可查看：

- 每一条单次训练记录及详情。
- 训练历史列表。
- 当前计划日程、今日训练内容和每个计划日的完成状态。

“当前计划日程与完成状态”和首页基础“本周节奏”都属于免费闭环。首页基础反馈不开放任意日期范围、历史周对比、完成率、周报结论或高级分析。

免费用户进入周统计详情页时：

- 展示 Pro 权益说明和报告示例结构。
- 不展示用户本周的真实统计数值。
- 用户主动点击“开通 Pro”后进入会员页。

后端的周统计详情、任意日期范围聚合、历史周趋势、周报和高级分析接口必须独立校验会员，不能只依赖前端隐藏入口；首页基础“本周节奏”接口保持免费。

### 6.5 会员状态和失败策略

- 没有有效付费会员记录的用户统一为免费用户。
- 会员状态查询失败时按免费权限处理，但不得阻止训练开始、保存和历史查看。
- Pro 接口无权限时返回统一业务错误，前端转换为同一会员权益弹窗。
- 套餐价格暂不在本规格中定版；现有测试价格可保留，但不得写成已确认上市价格。

## 7. 取消自动会员试用

当前版本不提供新用户自动试用，也不提供主动领取试用。

删除：

- 登录流程中的 `ensureTrialMembership` 或同义逻辑。
- `TRIAL_DAYS`、试用套餐编码和试用状态分支。
- 试用开始时间、试用结束时间等数据库字段。
- 试用中、试用剩余天数、试用结束等接口字段和页面文案。
- 围绕试用建立的测试和历史产品说明。

登录只建立登录态，不创建会员记录。用户完成支付后才创建或延长 Pro 权益。

以后若重新评估试用，需要单独形成新产品方案，不在当前代码中保留未启用的试用开关或兼容分支。

## 8. 训练等级 XP V2

### 8.1 有效训练

训练满足以下任一条件时可获得基础经验：

1. 至少完成 3 个非热身训练组；或
2. 训练时长至少 15 分钟，并且至少有 1 个动作包含已完成训练组。

保存失败、无已完成组或被删除的训练不结算经验。

### 8.2 经验规则

| 行为 | 经验值 |
| --- | ---: |
| 完成一次有效训练 | +20 XP |
| 完成当天计划训练 | +4 XP |
| 本次训练产生至少一个新 PR | +2 XP |
| 每日累计上限 | 26 XP |

规则说明：

- 同一天可以有多条有效训练，但所有训练累计最多获得 26 XP。
- 后续训练只能获得当天剩余可用经验。
- 每条训练记录最多结算一次，重复请求必须幂等。
- 单次训练即使产生多个 PR，PR 奖励仍最多 +2 XP。
- “完成当天计划训练”必须由有效计划日和训练记录关联关系判定，不能只相信客户端标识。
- 删除训练记录时回滚该记录产生的 XP，并重新计算用户累计经验和等级；被回滚的经验不再计入当日上限，避免通过创建、删除记录永久保留无来源经验。

### 8.3 删除的旧规则

- 删除 30 分钟统一门槛。
- 删除 60 分钟时长加成。
- 删除连续训练天数、连续达标周数和对应加成。
- 删除 `currentStreakDays` 等仅服务连续训练的接口字段和 UI。
- 首页、个人页、等级弹窗不再展示连续训练或连续加成。

现有等级曲线、等级阶段名称和徽章视觉保持不变。

训练完成页展示经验明细，例如：

```text
有效训练 +20
完成计划 +4
刷新纪录 +2
今日获得 26 XP
```

## 10. 系统边界与数据流

### 10.1 权限判断

```text
前端点击受限能力
  -> 查询或使用本地最新会员状态做友好预判
  -> 调用后端业务接口
  -> 后端再次校验有效会员或免费额度
  -> 允许操作，或返回统一会员权限错误
  -> 前端展示对应权益说明
```

后端是会员权限和免费额度的最终事实来源。

### 10.2 免费额度计数

- 自定义动作只统计当前用户创建且未删除的自定义动作。
- 自定义模板只统计当前用户创建且未删除的模板。
- 系统内容、其他用户内容和历史快照不计数。
- 额度判断和创建写入必须处于同一事务边界或具备等效并发保护。

### 10.3 XP 结算

```text
训练保存成功
  -> 判断是否已经结算
  -> 服务端计算有效组、时长、计划关联和 PR
  -> 计算本次理论 XP
  -> 查询当天已获得 XP
  -> 按 26 XP 日上限裁剪
  -> 写入经验流水
  -> 更新等级摘要
  -> 返回本次 XP 明细
```

## 11. 异常与边界

- 会员状态接口失败：按免费权限展示；训练保存和历史查看不受影响。
- 支付成功但状态同步延迟：允许刷新订单状态后重新拉取会员状态，不重复创建权益。
- 免费用户并发创建两项内容：服务端保证最终最多保留免费额度允许的数量。
- Pro 到期且已有超额内容：不删除、不隐式修改；限制新增、复制和编辑。
- 周统计详情、任意日期范围聚合、历史周趋势、周报或高级分析接口被免费用户直接调用：后端返回会员权限错误，不泄露受限数值；首页基础“本周节奏”接口正常返回。
- XP 重复结算：由训练记录唯一键或经验流水唯一约束阻止。
- 当日已获得 25 XP：后续理论奖励高于 1 XP 时只结算 1 XP。
- 删除已结算训练：反向记录或撤销对应经验流水并重算等级，不能只删除训练而保留 XP。
- 删除画像字段后：任何页面和接口不得继续依赖画像完成状态决定可用性。

## 13. 测试要求

- 登录不创建试用会员。

- Pro 用户不受自定义内容数量限制。

## 15. 验收结论

本轮完成后应满足：

- 新用户无需填写画像即可选择计划并完成训练。
- 训练开始、保存、历史和系统计划不被会员阻断。
- 首页基础“本周节奏”免费；收藏、周统计详情、历史周趋势、周报和高级分析明确属于 Pro。
- 免费用户拥有 1 个自定义动作和 1 个自定义训练模板额度。
- 登录不会自动开始会员试用。
- 等级只奖励有效训练、计划完成和 PR，不包含连续训练因素。
- 当前代码和数据库不包含无用画像、试用和连续训练兼容结构。
- 产品事件漏斗、公开分享、二维码和归因不进入当前版本。
- 产品总览、技术文档、数据库注释和实现保持一致。
