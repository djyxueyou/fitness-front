# FitForge 高级分析、会员与分享设计

> 已于 2026-07-19 被 `2026-07-19-fitforge-product-scope-membership-level-redesign.md` 替代。当前采用会员方案 A，不提供自动试用；动作收藏与全部周统计属于 Pro，自定义动作和模板各有 1 个免费额度，公开分享/二维码/归因暂缓。本文仅作为历史决策记录。

## 1. 目标

在不阻断基础训练记录的前提下，用可理解的训练结果、进阶建议和长期趋势建立 Pro 价值，并通过轻量分享支持自然增长。

## 2. 范围

### 包含

- 基础分析与高级分析分层。
- 高级训练报告。
- 会员页价值重构。
- 试用触发策略设计。
- 单次训练、周复盘和计划分享。

### 不包含

- 公共社交动态。
- 教练版。
- 创作者计划市场。
- 广告商业化。
- 修改现有支付流程。

## 3. 权益分层

### 3.1 免费能力

- 不限次数保存训练。
- 基础周统计。
- 最近训练记录。
- 基础训练详情。
- 系统计划和系统模板。
- 本地训练草稿与保存失败重试。

### 3.2 Pro 能力

- 渐进超负荷建议和推荐原因历史。
- 完整训练历史趋势。
- 动作趋势和估算 1RM。
- 肌群训练量分布。
- 平台期和训练偏差提示。
- 高级周报与周期报告。
- 无限自定义计划和模板。
- 自动化数据导出。

所有 Pro 入口必须先展示当前用户可获得的具体结果，再展示会员购买页。

## 4. 高级分析

### 4.1 分析首页

首屏顺序：

1. 结论摘要。
2. 时间范围切换。
3. 核心趋势。
4. 需要关注。
5. 动作与肌群明细。

示例结论：

> 过去四周完成 11 次训练，卧推容量提升 18%，背部训练频率低于计划目标。

### 4.2 高级报告模块

#### 动作进步

- 最大重量趋势。
- 总容量趋势。
- 估算 1RM 趋势。
- 最近建议与采纳结果。

#### 训练平衡

- 肌群组数分布。
- 计划目标和实际完成差异。
- 连续未训练肌群提示。

#### 执行稳定性

- 周训练频率。
- 计划完成率。
- 错过训练后的恢复率。
- 平均训练时长。

#### 平台期提示

首版定义：

- 同一动作至少有四次有效记录。
- 最近三次训练最大重量、总次数和总容量均无明显提升。
- 提示只说明“可能进入平台期”，并给出检查方向，不自动改计划。

### 4.3 数据不足状态

不展示空图表，改为可执行说明：

> 再完成 2 次卧推训练，即可生成重量趋势和进阶判断。

## 5. 会员页

### 5.1 页面结构

1. 当前用户专属价值摘要。
2. 三个主要 Pro 结果。
3. 免费与 Pro 对比。
4. 套餐选择。
5. 试用或购买主按钮。
6. 自动续费、到期和恢复购买说明。

### 5.2 个性化价值摘要

根据当前数据选择一个最相关场景：

- 已有多次训练：展示可解锁的动作趋势。
- 已启用计划：展示可解锁的进阶建议。
- 数据不足：展示完成更多训练后可生成的报告示例。

不得伪造用户尚未产生的进步数据。

### 5.3 试用触发

推荐测试两个触发点：

- 用户完成第三次有效训练后。
- 用户首次点击高级建议或高级报告时。

试用建议为 7 或 14 天。现有 30 天试用可作为对照实验，不在设计阶段直接移除。

## 6. 分享能力

### 6.1 分享原则

- 分享为主动操作，默认不公开敏感数据。
- 分享卡片使用现有年轻、干净、偏 iOS 的视觉体系。
- 分享内容提供隐私开关。
- 分享不要求接入公共社区。

### 6.2 单次训练总结卡

默认包含：

- 训练名称。
- 日期。
- 动作数、组数、时长。
- PR 数量。
- FitForge 品牌标识。

可选公开：

- 总容量。
- 具体重量。
- 修为结算结果。

### 6.3 周复盘卡

默认包含：

- 周训练次数。
- 总时长。
- 完成率或连续训练天数。
- 一条本周亮点。

### 6.4 计划分享

- 生成只读计划链接或小程序分享路径。
- 接收方可以预览计划。
- 登录后可以复制为“我的计划”。
- 复制后独立编辑，不影响分享源计划。

## 7. Pro 能力触达规则

| 场景 | 触达方式 |
| --- | --- |
| 查看基础分析 | 不弹会员提示 |
| 点击锁定高级报告 | 先展示该报告可回答的问题，再进入会员页 |
| 查看推荐摘要 | 免费展示是否有建议 |
| 查看完整建议原因和历史 | 进入 Pro 说明 |
| 保存基础训练 | 不触达会员 |
| 创建超出免费限额的自定义计划或模板 | 明确说明限额和升级价值 |

同一用户七天内不得重复自动弹出相同会员提示。用户主动点击不受限制。

## 10. 异常与边界

- 分析数据不足：展示数据准备度和下一步，不展示锁定空图表。
- 会员状态请求失败：按免费状态展示，但不阻止基础功能。
- 支付失败或取消：保留会员页选择，明确显示结果。
- 分享图片生成失败：允许重试，不丢失隐私选项。
- 分享计划已删除或停用：显示不可用状态，不允许复制。
- 分享卡片不得默认包含身体指标、备注或伤病限制。

## 11. 验收标准

- 免费用户能够完成完整基础训练闭环。
- 高级分析先展示结论，后展示图表。
- 数据不足时提供明确的生成条件。
- 会员页能根据用户当前状态展示真实价值，不伪造数据。
- 自动会员提示有频率限制。
- 分享卡片默认不包含敏感训练数据。
- 分享计划可以只读预览并复制为独立计划。
