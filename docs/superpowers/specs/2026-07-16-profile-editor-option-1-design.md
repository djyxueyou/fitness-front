# 个人资料方案 1 设计规格

## 目标

以已确认的方案 1 为视觉基准，把资料编辑改成微信式的“总览列表 + 聚焦编辑”流程，同时让个人卡片中的等级入口更轻、更明确。

## 页面结构

### 我的

- 头像、昵称和“编辑资料 ›”仍组成一个明确的页面导航入口。
- 等级改为昵称下方的青铜色胶囊按钮，文案为真实的 `Lv.N · 段位名`，不使用箭头。
- 点击等级胶囊打开现有等级弹框；升级进度和剩余 XP 只做信息展示，不扩大为整行点击区。
- 等级路线只展示段位名和真实等级范围，不再以卡片顺序伪造 Lv.1、Lv.2。

### 个人资料总览

- 使用浅色背景、白色圆角分组列表和细分割线。
- 顶部居中标题“个人资料”，保留返回入口。
- 第一组为头像、昵称、身高；第二组标题为“训练资料”，包含训练目标和训练经验。
- 头像点击后立即选择、压缩并上传；上传成功后刷新 COS 地址。
- 昵称和身高进入单字段编辑页。
- 训练目标和训练经验使用底部选择器，选择后立即保存。
- 不保留全局底部“保存资料”按钮，也不展示身体指标、训练偏好等重复入口。

### 单字段编辑

- 标题根据字段显示“修改昵称”或“修改身高”。
- 右上角为保存按钮，无变化、校验失败或保存中时禁用。
- 昵称限制 2–20 个字符；身高允许为空，否则限制 80–250 cm。
- 保存成功后返回总览页。

## 头像异常与临时文件

- `chooseImage:fail cancel` 属于用户正常取消：不显示错误、不输出错误日志。
- 原始选择文件和压缩文件在上传成功或失败后的 `finally` 阶段尽力删除。
- 清理失败不得覆盖上传结果，也不得向用户报错。
- 页面不以待删除的临时文件作为长期头像地址；成功后只展示刷新得到的服务端/COS URL。

## 验收标准

- 头像取消全程静默。
- 头像上传成功、失败两条路径都会触发临时文件清理。
- 个人资料总览没有全局保存按钮。
- 昵称、身高、训练目标、训练经验四项都可独立保存。
- 个人卡片同时存在“编辑资料 ›”和无箭头等级胶囊，视觉语义不重复。
- 微信小程序类型检查、测试和构建通过。
