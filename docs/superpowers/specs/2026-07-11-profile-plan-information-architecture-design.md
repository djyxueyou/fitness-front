# FitForge 我的页与训练信息架构设计

> 训练画像和等级连续训练部分已于 2026-07-19 被 `2026-07-19-fitforge-product-scope-membership-level-redesign.md` 替代。当前“我的”页不含画像入口，等级采用 XP V2。

## 目标

将“我的”Tab 重构为简洁、接近 iOS inset grouped list 的个人中心，同时明确计划、模板、训练日历和历史记录的归属。实现以用户选定的视觉方案 1 为基准，并沿用现有橙色品牌色与四项 Tab Bar。原“计划”Tab 更名为“训练”，用于承载完整的训练闭环。

## 信息架构

- “我的”只承载个人身份、训练成就、健康资料、账户与服务。
- “模板管理”从“我的”移入“训练”业务域，入口正式命名为“我的模板”。
- “我的模板”与“我的计划”属于同一级用户训练资产，但使用独立区块或入口，不混入同一个列表。
- “历史记录”不再作为“我的”独立入口，与训练日历一起成为“训练”Tab 的一级视图。
- 训练日历回答“哪天计划或训练了”，历史视图回答“最近完成了什么训练”。
- “训练”覆盖未来计划、我的模板、日期安排和过去记录；“我的”只负责个人与账户。

## 底部导航

底部继续保持四个 Tab，不新增第五个记录 Tab：

- 首页。
- 训练。
- 动作库。
- 我的。

保留四项导航可以避免在“计划”和“记录”之间拆散同一条训练闭环，也能保持小屏设备上的标签和触控空间。“记录”只有在未来发展为包含趋势、周报、PR 和身体变化的独立高频数据中心时，才重新评估是否升级为底部 Tab。

## 我的页结构

页面采用浅灰系统背景、白色分组容器、轻分隔线和统一线性图标。橙色只用于等级进度与 Tab 选中态。

### 个人与训练概览

- 页面使用大标题“我的”。
- 顶部个人概览整组可点击并进入个人资料。
- 展示头像、昵称和训练等级。
- 等级与三项统计合并在一个容器内，避免卡片嵌套。
- 统计保留连续训练、累计训练、累计容量。

### 健康资料

- 个人资料。
- 身体指标。

### 账户与服务

- 会员中心。
- 我的收藏。
- 设置。
- 关于。

历史记录和模板管理不在此页面展示。

## 训练页结构

- 原“计划”Tab 和页面标题统一更名为“训练”。
- 顶层采用“计划 / 日历 / 历史”三个平级视图，不使用“记录”下面再嵌套“日历 / 历史”的两层分段。
- 作为 Tab 根页面时不显示返回按钮。

### 计划视图

- 当前安排是首要区域。
- 我的计划与我的模板同级展示。
- 推荐计划作为发现和启用计划的独立区域。
- 我的计划表示按周期推进、包含训练日和执行进度的训练安排。
- 我的模板表示可重复使用的一次训练动作组合。
- 我的计划、我的模板和推荐计划不混排为同一个列表。

### 日历视图

- 展示月份、计划日、已训练和待处理状态。
- 展示选中日期的计划安排和训练记录。
- 保留训练分析入口。
- 日历同时连接未来计划和过去结果，因此属于“训练”而不是单独的历史模块。

### 历史视图

- 按时间倒序展示已完成训练。
- 用于快速查找训练名称、时间、容量和完成情况。
- 训练条目进入既有训练详情页。

### 首页快捷入口

- 首页保留训练日历入口，点击后直接打开“训练 → 日历”。
- 首页的近期训练记录入口直接打开“训练 → 历史”。
- 首页入口负责快速抵达，训练 Tab 负责完整浏览和管理。

本轮实现优先完成“我的”页重构、底部 Tab 命名和入口迁移所需的前端导航调整。训练页当前存在用户未提交修改，实施时必须先核对并保留这些改动，再决定三分段结构与我的模板入口的最小安全落点。

## 视觉规范

- 背景沿用浅色主题变量，目标观感接近 iOS grouped settings。
- 页面横向安全边距使用现有 Tab 页面尺度，视觉目标约为 16pt。
- 分组容器圆角约 12–16pt，不使用明显投影。
- 列表行最小视觉高度 44pt，整行可点击。
- 正文以 15–16pt 等效字号为基准；辅助文字必须保持可读对比度。
- 使用项目已有图标资源或统一图标方案，不再使用 Emoji 或文本符号模拟图标。
- 保持现有暗色主题能力，不写死只适用于浅色主题的文本和背景颜色。

## 行为与状态

- 鉴权、资料刷新、等级详情、退出登录和训练草稿入口保持现有行为。
- 个人概览点击进入个人资料；等级区域仍可进入等级详情。
- 所有列表行继续通过现有 route 常量导航。
- 首页打开日历或历史时，需要携带目标视图参数；训练 Tab 根据参数切换到对应分段。
- 用户直接点击训练 Tab 时，默认进入“计划”视图。
- 加载、未登录跳转和接口失败行为不改变。

## 验收标准

- “我的”页不再展示历史记录和模板管理入口。
- 底部 Tab 显示“训练”而不是“计划”，并继续保持四项。
- 训练页顶层提供“计划 / 日历 / 历史”三个平级视图。
- “我的计划”和“我的模板”在计划视图中同级展示且不混入同一列表。
- 首页训练日历和近期记录入口可以分别直达日历与历史视图。
- 页面不出现卡片套卡片、Emoji 图标或多余彩色图标底板。
- 个人资料、身体指标、会员中心、收藏、设置和关于均可正常进入。
- 等级详情、统计数据、主题切换和 Tab Bar 行为保持正常。
- H5 与微信小程序构建不出现模板或样式错误。
- 前端格式检查和 TypeScript 检查通过。
- 视觉检查确认常见手机宽度下无裁切、重叠或底部 Tab 遮挡。

## 非目标

- 本轮不修改后端接口或数据结构。
- 本轮不重做等级详情弹层。
- 本轮不新增训练记录数据模型。
- 本轮不新增第五个底部 Tab。
- 本轮不重绘整套 Tab Bar 图标。
